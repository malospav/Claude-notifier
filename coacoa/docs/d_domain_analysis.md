# Анализ предметной области — claude-notifier

Источник: интервью с пользователем 2026-11-16 (`/analyst`), идея в [docs/idea.md](../../docs/idea.md).

## 1. Проблема
Когда пользователь запускает задачу в Claude Code и переключается на другие окна, он не знает, что Claude уже закончил, ждёт разрешения, упал с ошибкой или упирается в лимит. Claude простаивает, а пользователь теряет время, проверяя окна вручную.

## 2. Персона
| Персона | Контекст | Главная боль |
|---|---|---|
| **Разработчик-оператор** (единственный пользователь) | Windows 11; работает в Claude Code (desktop-вкладка Code и CLI в терминале); параллельно занят в других окнах | Не замечает момент, когда **Сессия** ждёт его ввода или завершилась, поэтому теряет время |

## 3. Job Stories
- **J-1** Когда Claude закончил задачу, я хочу увидеть всплывающее уведомление с превью его последнего сообщения и услышать звук, чтобы сразу понять, готово ли, не открывая окно.
- **J-2** Когда Claude ждёт разрешения или ответа, я хочу получить уведомление с отдельным звуком, чтобы он не простаивал.
- **J-3** Когда сессия упала с ошибкой, я хочу услышать отдельный «тревожный» звук, чтобы быстро вмешаться.
- **J-4** Когда я приближаюсь к лимиту использования, я хочу заранее получить предупреждение, чтобы спланировать работу.
- **J-5** Когда я кликаю по уведомлению, я хочу попасть в ту самую сессию Claude (desktop-чат или окно терминала), к которой относится событие.
- **J-6** Когда мне нужно временно тишины или нужно поменять звуки, я хочу сделать это через иконку в трее, не правя файлы.

## 4. Требования, собранные на интервью
| # | Решение пользователя |
|---|---|
| R-1 | События: **Задача завершена**, **Нужно разрешение**, **Ошибка**, **Лимит использования**. |
| R-2 | Каналы: нативное toast-уведомление Windows + звук. Telegram и другие мессенджеры не нужны. |
| R-3 | Источники: Claude Code desktop (вкладка Code) и Claude Code CLI. Чат claude.ai и API не нужны. |
| R-4 | Уведомлять **всегда**, даже если окно Claude активно. |
| R-5 | В уведомлении — **превью** сообщения Claude; клик открывает **нужную сессию**. |
| R-6 | **Свой звук** для каждого типа события. |
| R-7 | Форма: фоновая программа с **иконкой в трее**. |

## 5. Ограничения
- ОС: Windows 11 Pro; включён Smart App Control. При установке CoaCoA он заблокировал неподписанную DLL `pydantic_core`. Значит, решения на неподписанных нативных бинарниках из pip/npm могут не запуститься.
- Python 3.12 доступен только через `py` (команда `python` открывает Microsoft Store). Git 2.56 установлен.

## 6. Глоссарий
| Термин | Определение |
|---|---|
| **Сессия** | Один разговор с Claude Code: вкладка в desktop-приложении или запущенный `claude` в терминале. |
| **Событие** | Изменение состояния сессии, о котором нужно уведомить. Типы перечислены в R-1. |
| **Хук** | Механизм Claude Code, который запускает внешнюю команду при событии сессии. |
| **Toast** | Нативное всплывающее уведомление Windows в углу экрана и в Центре уведомлений. |
| **Превью** | Укороченный текст последнего сообщения Claude в уведомлении. |
| **Трей** | Область значков у часов на панели задач Windows. |

## 7. Открытые вопросы
- **Q-1** Какой хук Claude Code соответствует каждому событию из R-1? Отдают ли хуки текст последнего сообщения для превью или его нужно читать из файла транскрипта? *Проверить по документации Claude Code.*
- **Q-2** Срабатывают ли пользовательские хуки из `~/.claude/settings.json` в сессиях desktop-приложения так же, как в CLI?
- **Q-3** Как открыть **конкретную** desktop-сессию по клику: есть ли у приложения Claude deep-link? Для CLI — как найти и активировать нужное окно терминала?
- **Q-4** Откуда брать данные о лимите (R-1 «Лимит использования») и какой порог считать «приближением»?
- **Q-5** Нужна ли история уведомлений в меню трея и пауза или режим «не беспокоить» с таймером?
- **Q-6** Должна ли программа запускаться вместе с Windows?
- **Q-7** Какие звуки использовать: системные звуки Windows или свои WAV-файлы, выбираемые в трее?
- **Q-8** Какой стек выбрать (Python, .NET, Node), чтобы Smart App Control не блокировал программу (§5)? *Решение — на этапе архитектуры.*
