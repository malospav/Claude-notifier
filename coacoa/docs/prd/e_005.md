# Epic e_005 — Трей-программа и история

## Goal

Фоновая программа с иконкой в трее, которая принимает события, показывает уведомления и хранит историю.

## Acceptance Criteria

- [ ] Иконка в трее; меню «История ▸» и «Выход».
- [ ] «История» показывает последние 20 событий: время, тип, проект.
- [ ] Клик по пункту истории действует как клик по toast (e_003).
- [ ] История ≤ 100 событий сохраняется на диск и переживает перезапуск.
- [ ] Только один экземпляр программы; повторный запуск не создаёт вторую иконку.
- [ ] В простое ≤ 150 МБ RAM; лог с ротацией ≤ 1 МБ.
- [ ] README: установка, удаление, отключение встроенных уведомлений desktop-приложения Claude.

## Out-of-Scope

- Автозапуск с Windows, «Не беспокоить», окно настроек.

## Notes

Принимает события от хук-моста (e_001) только локально: без сети.
