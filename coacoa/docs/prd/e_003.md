# Epic e_003 — Переход к сессии по клику

## Goal

Клик по уведомлению выводит на передний план окно той сессии, к которой относится событие.

## Acceptance Criteria

- [ ] Для CLI-сессии клик активирует окно терминала, в котором запущен `claude`.
- [ ] Для desktop-сессии клик активирует окно приложения Claude.
- [ ] Свёрнутое окно разворачивается.
- [ ] Если окно уже закрыто, ошибок нет, а в истории событие помечено «сессия закрыта».
- [ ] Клик по пункту истории в трее работает так же.

## Out-of-Scope

- Открытие конкретного чата внутри desktop-приложения: документированного deep-link нет.

## Notes

Как отличить desktop от CLI и найти окно терминала, решает архитектор (PRD OQ-1).
