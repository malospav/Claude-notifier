# Epic e_001 — Хук-мост и установщик

## Goal

Получать события Claude Code (`Stop`, `Notification`, `StopFailure`) и передавать их трей-программе, не мешая работе Claude.

## Acceptance Criteria

- [ ] Установщик добавляет хуки `Stop`, `Notification` (матчер `permission_prompt|elicitation_dialog|agent_needs_input`) и `StopFailure` в `~/.claude/settings.json`; чужие записи сохраняются.
- [ ] Повторная установка не создаёт дублей; деинсталлятор удаляет только свои записи.
- [ ] `Stop` → событие «Готово» с превью из `last_assistant_message`.
- [ ] `Notification` → «Нужно разрешение» с текстом из `message`.
- [ ] `StopFailure` → «Ошибка» с `error` и `error_details`.
- [ ] Хук завершается за ≤ 500 мс с кодом 0, даже если трей-программа недоступна.
- [ ] Если трей-программа не запущена, хук запускает её, и событие не теряется.

## Out-of-Scope

- Хуки `SubagentStop`, `SessionEnd`, `idle_prompt`.

## Notes

Работает и в desktop, и в CLI: по документации хуки срабатывают одинаково. Облачные сессии не читают локальный `settings.json`.
