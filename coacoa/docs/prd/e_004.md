# Epic e_004 — Предупреждения о лимитах

## Goal

Предупреждать о приближении к 5-часовому и недельному лимиту использования Claude.

## Acceptance Criteria

- [ ] Скрипт `statusLine` читает `rate_limits.five_hour.used_percentage` и `rate_limits.seven_day.used_percentage`.
- [ ] При ≥ 80 % и ≥ 90 % создаётся событие «Лимит» с названием окна, процентом и временем сброса (из `resets_at`).
- [ ] Каждый порог срабатывает один раз за окно; после смены `resets_at` счётчик сбрасывается.
- [ ] Если поля `rate_limits` нет, скрипт работает без ошибок и без событий.
- [ ] Скрипт выводит строку статуса: модель, % контекста, % лимитов.
- [ ] Пороги меняются в файле настроек.

## Out-of-Scope

- `spend_limit` (Claude apps gateway).

## Notes

`rate_limits` есть только у Pro, Max и Ultra и только после первого ответа. Работает ли `statusLine` в desktop-приложении, не проверено (PRD OQ-2).
