# Epic e_002 — Toast-уведомления и звуки

## Goal

Показывать нативный toast Windows 11 со звуком, по которому понятно, какого типа событие.

## Acceptance Criteria

- [ ] Toast: заголовок «<Тип> · <папка проекта>», текст — превью ≤ 200 символов, лишнее обрезается многоточием.
- [ ] 4 типа событий («Готово», «Нужно разрешение», «Ошибка», «Лимит») по умолчанию играют 4 разных системных звука Windows.
- [ ] В файле настроек можно задать путь к своему WAV для любого типа; если файла нет, играет системный звук.
- [ ] Каждый тип можно выключить в файле настроек.
- [ ] Toast показывается, даже если окно Claude активно.
- [ ] Событие → toast ≤ 1 с (P95 на 20 замерах).

## Out-of-Scope

- Режим «Не беспокоить», настройки через меню трея.

## Notes

Toast должен работать при включённом Smart App Control (NFR Compatibility).
