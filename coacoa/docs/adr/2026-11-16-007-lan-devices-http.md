# ADR-007: Сеансы с других устройств — HTTP-сервер в локальной сети на ПК

- **Статус:** принято, 2026-11-16
- **Контекст:** пользователь работает с Claude Code на ПК (Windows) и двух MacBook и хочет видеть сеансы всех устройств в одном окне. С телефона он хочет хотя бы смотреть список. Все устройства в одной сети Wi-Fi. Публичного API со списком сеансов аккаунта Claude нет, хуки Claude Code срабатывают только на своём устройстве. Подключение устройства должно занимать «1 клик» из интерфейса.

## Решение

1. **Сервер на ПК.** Трей слушает `http://+:47600/` (HttpListener). Фоновый runspace только принимает соединения. Запросы обрабатываются в UI-потоке трея, где лежат все данные, поэтому общего состояния между потоками нет.
2. **Разовая настройка с UAC.** Нужны резервация URL (`netsh http add urlacl`) и правило брандмауэра: TCP 47600, `remoteip=localsubnet`, `profile=any`. Профиль `any` выбран потому, что Wi-Fi на этом ПК помечен как «Общедоступная», а менять тип сети мы не хотим. Настройку выполняет `setup-network.ps1`, трей запускает его с `-Verb RunAs` при первом включении. Всё остальное работает без прав администратора.
3. **Подключение по одноразовому PIN.** «Подключить устройство» показывает адрес ПК и PIN: 6 цифр, 10 минут, 5 попыток. Браузер устройства вводит PIN и получает cookie с токеном на год.
4. **Mac.** На странице есть кнопка «Получить команду установки». Она выдаёт одноразовую команду `curl … /install/<код> | sh`. Скрипт установки:
   - кладёт `~/.claude-notifier/hook.sh` и `env` с отдельным токеном хуков;
   - добавляет 6 хуков в `~/.claude/settings.json` через JXA (`osascript -l JavaScript`). JXA есть в каждой macOS, а `python3` и `jq` не гарантированы.

   `hook.sh` отправляет сырой JSON хука на `/api/event`. Разбирает его тот же `ConvertTo-NotifierEvent`, что и на ПК, поэтому логика не дублируется.
5. **Токены.** У каждого устройства свои токены, на ПК хранится только их SHA-256 (`network.json`). Отключение устройства сразу отзывает все его токены.
6. **События с Mac** обновляют `sessions.json` с полем `device`. Уведомления на ПК для каждого устройства включаются отдельно, по умолчанию выключены.

## Отвергнутые варианты

- **Общая облачная папка (OneDrive):** задержка синхронизации, нужен клиент облака на каждом устройстве, страницы для телефона нет.
- **Внешний сервер-ретранслятор:** нужны хостинг и авторизация. Для одного пользователя в одной сети это избыточно.
- **mDNS-имя как основной адрес:** Windows на «Общедоступном» профиле может не отвечать на mDNS. Имя `<ПК>.local` используется только как запасной адрес в `hook.sh`.

## Последствия

- Трафик внутри сети идёт по HTTP без шифрования (токен, превью ответов). Для домашней сети это приемлемо и описано в README.
- Если ПК выключен или Mac вне дома, события теряются: хук ждёт ответа не больше 2 с.
- Сеансы приложения Claude на телефоне не видны, потому что там нет хуков.
- Перейти к окну можно только для сеансов ПК.
